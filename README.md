# EDA Project

This repository contains an Exploratory Data Analysis (EDA) project focused on understanding the dataset, identifying patterns, and visualizing key insights.

## Project Overview

The goal of this project is to explore the dataset in a structured way by:
- cleaning and preparing the data,
- understanding missing values and data types,
- summarizing important statistics,
- visualizing relationships and trends,
- drawing meaningful conclusions from the data.

## Dataset

This project uses the Titanic dataset, which contains information about passengers and some key attributes such as age, gender, ticket class, fare, cabin, and survival status.

## Tools and Libraries

The analysis is performed using:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## What This Project Includes

- Data loading and inspection

- Data visualizations for better interpretation

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/Ramsha-93/EDA_Project.git
cd EDA_Project
```

2. Install the required dependencies:
```bash
pip install pandas numpy matplotlib seaborn
```

3. Run the analysis script:
```bash
python analysis.py
```

## Expected Outcomes

This project helps in understanding:
